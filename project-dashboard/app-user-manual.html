Getting Started

Quick start

  1. Choose the job you need from the sidebar.
  2. Use Browse to pick the source folder and the output folder.
  3. Choose only the options that apply to this job.
  4. Start the job and leave the app open until the done screen appears.
  5. Open the output folder from the done screen and review the files before sharing them.
The Light, Dark, and System buttons in the lower-left sidebar change this manual and the app together.

Content List

Use Content List when you need a spreadsheet of files or folders. The app goes through the source folder and writes one row for each item it includes. Turn on a verification hash only when you need a fingerprint to check copies against later.

Agency Template

Use Agency Template when the spreadsheet must match the area agency headers. Turn on Use agency content-list headers on the Content List screen, and the agency fields appear below it. Fill in only the values that should be the same for the entire sheet. These fields start blank for every new scan so a value from an earlier job cannot be reused by mistake.

Clone Compare

Use Clone Compare to check whether two drives or folders contain the same files. Pick the first drive, the clone, and a folder for the results. One Hash Algorithm setting covers both sides. Single drive mode lets you scan the first drive, swap the media over, then scan the second — the app tells you when to eject and what to do next.

Soft compare matters for PDFs. The same PDF copied by some tools gets a new internal ID, which makes it look changed when nothing you can see has changed. With Soft compare on, those are reported as Metadata Clone instead of Not a Clone.

Exact Clone
Everything checked matched.
Content Clone
The files appear to match, but folder layout or saved details differ.
Metadata Clone
The app found likely PDF saved-detail differences only.
Not a Clone
Files are missing, extra, or different.

Getty Tags

Use Getty Tags to check the Tags column of a CONTENTdm export before you upload it. It takes out the hidden characters that stop the upload, and checks every term against the Getty Art & Architecture Thesaurus. Your export is never changed — the app writes a corrected copy beside it.

  1. Export the Access Main table to Excel as you normally would.
  2. Browse to the exported sheet. Excel, CSV, and tab-delimited text files all work.
  3. Choose where terms should be checked, using the table below.
  4. Click Check Tags. Rows with nothing wrong are not listed.
  5. Fix what it found. Edit a tag, or click one of the suggested replacements.
  6. Click Apply Fixes & Re-check. Repeat until nothing is left.
  7. Upload the cleaned copy, not the original.

Getty, liveInternet access to GettyAlways, when it is reachable. It is the only up-to-date source.

Choosing Getty, live shows whether Getty can be reached from this computer, in green or red. It checks once, when you pick it. If your network changes — a VPN comes on, or support opens something up — click Check again.

Need a fresher list? The Getty Tags screen links to Getty's download centre. Take only the file named aat_rel_<mmyy>.zip — nothing else on that page can be read here — then use Build list from a Getty archive, and the app turns it into a term list beside it.

The app will not do that download for you: Getty's download site is not a secure one, and this app only makes secure connections. Some workplaces block that site too. Neither affects the live check.

Any list held on this computer — the built-in one, or one you build — answers for the day it was made, and each shows its own date. Getty keeps changing the thesaurus, so a list can still accept a term Getty has since renamed. The app tells you when an answer came from a dated list. Use the live check whenever you can reach it.

Each finding starts with what it wants from you. Fixed means the app already corrected it and there is nothing to do. Must Fix means correct it before uploading. Review means it is your judgement call and will upload either way.

  • The report is named with -tags-report and lists what was found and what changed.
  • Use Show in Folder to find both files.
  • A sheet with nothing to correct does not get a cleaned copy, so there is no doubt about which file to upload.

Why the built-in list is smaller than the AAT. Getty counts 503,230 terms across 74,460 concept records. The built-in list holds about 176,000 — the Getty Tags screen shows the exact count for your version. Nothing is missing — the two counts measure different things.

All AAT terms
503,230
Getty’s own count, across every language the AAT holds.
English terms
187,988
The AAT is multilingual: one concept record carries its terms in English, Spanish, Dutch, Chinese, German and more. This app assumes English tags, for now, so only the English terms are kept.
Distinct spellings
176,629
The same spelling can be a term in several concept records — “landscapes” is both the landform and the genre. The list holds it once, because it answers whether the spelling is an AAT term, not which concept record it belongs to.

So most of the gap is other languages, and the rest is spellings that repeat. Of the terms that remain, about 56,000 are preferred terms and about 120,000 are variant terms — and each variant knows the preferred term that replaces it.

Getty keeps revising the AAT, and the built-in list comes from whichever Getty archive this version of the app was built with, so these counts and the ones on Getty’s own pages will drift apart over time. The live check is not a copy at all: it asks Getty directly and sees everything Getty holds today. It looks at English terms only, the same as the built-in list.

Reference

Outputs

  • The app names output files with the source folder name and the date and time of the job.
  • CSV files open in Excel and other spreadsheet tools.
  • XLSX files are Excel workbooks. Create one when the final handoff should be an Excel file.
  • The report file includes totals, the options used, skipped-file examples, and file type summaries.
  • Very large jobs may be split into multiple spreadsheet parts so Excel can still open them.

Reference

Updates

On Windows, the app looks in the X:\Apps folder for a newer content-list-generator.exe from support. Open About if support gives you a different folder.

  • It only installs a newer app file from that folder, and only one support has signed.
  • When an update is ready, restart the app from the update prompt.

Support

Troubleshooting

macOS security prompt

Right-click the app, choose Open, then confirm. You usually only need to do this the first time.

Windows SmartScreen

Choose More info, then Run anyway if this app came from your trusted release location.

Slow scans

Network drives, very large files, and verification all add time. Choose Off for verification when you only need a quick list.

Reset settings

Open About and share the settings location with support if the app needs to be reset.
